# 纪念日应用

一个简洁优雅的纪念日管理应用，完美适配深色和浅色模式。

## 主要功能

<!-- 已移除语音识别相关功能 -->

### 🌙 深色模式适配
- **完整适配**：所有界面完美支持深色和浅色模式
- **智能颜色**：根据系统主题自动调整颜色方案
- **一致体验**：保持视觉一致性和用户体验

### 📱 核心功能
- **纪念日管理**：添加、编辑、删除纪念日
- **倒计时显示**：实时显示距离纪念日的天数
- **重复设置**：支持年重复、月重复等
- **特殊倒计时**：高考倒计时、放假倒计时

### 🎨 界面特色
- **现代化设计**：简洁优雅的界面设计
- **流畅动画**：丰富的交互动画和反馈
- **震动反馈**：触觉反馈增强用户体验
- **下拉刷新**：支持下拉刷新纪念日列表

### 手动创建纪念日
1. 点击主页的"+"按钮
2. 填写纪念日标题和日期
3. 选择重复类型（可选）
4. 保存创建

### 设置功能
- 显示/隐藏过期事件
- 高考倒计时开关
- 放假倒计时开关
- 3D效果开关
